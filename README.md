# vibe.mytotalcost.com | The Token & Pixel Optimization Hub

A high-performance premium single-page dashboard designed to measure, audit, and optimize token margins, vector footprints, prompt caches, and image tiling grids before sending queries to expensive LLM agents (Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro).

## Key Features

### 💻 Developer Code Workspace
- **📊 Token Burn Calculator**: Real-time modeling of codebase context payload overheads, dynamic billing estimates, and lockout Rate Limit warnings.
- **🗜 Prompt Compactor**: Automatic code whitespace compression, comment stripping, and cache sequence alignment scores.
- **🔌 Local First Wizard**: Host hardware detection (M-Max Silicon, CPU, RTX 4090s) with exportable Ollama configurations for Continue.dev, Cline, or Cursor IDE overrides.
- **🛡 .cursorrules Builder**: Quick checkbox compilation for robust, token-saving agent instructions.
- **🚀 Git Token Auditor CLI Simulation**: Typewriter-style shell console scanning repositories to flag unignored package directories.

### 🎨 Creative Media Workspace
- **👁 Vision Tile Estimator**: Real-time visual canvas grid partition counts matching multimodal model tile sizes (Claude aspect ratios vs GPT 512x512 grids).
- **🕸 SVG Vector Optimizer**: Interactive path minimization, editor comment removal, and instant side-by-side token efficiency rendering.
- **🔊 Audio & Video Planner**: Sampling FPS frame-rate trackers and time-based context estimator widgets.

---

## 🛠 Tech Stack
- **Core Markup**: Semantic HTML5 structures.
- **Styling system**: Tailwind CSS CDN coupled with bespoke HSL glows, scrollbars, and keyframe animations in `styles.css`.
- **Logic engine**: Vanilla JavaScript state controller `app.js`.

## 📦 How to run locally
Simply open the `index.html` file in any modern web browser or start a lightweight development server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
